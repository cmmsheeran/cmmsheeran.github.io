Many microscopic systems appear to support a simpler description at larger scales, but not every aggregation produces an autonomous macroscopic theory. This project asks when a set of coarse variables is sufficient to predict its own dynamics and what is lost when it is not.

## Approach

I use network renormalization, message passing, linear response, and dynamical closure tests to track how interactions and observables change under coarse-graining. The objective is to identify scales that are not only structurally compact but mechanistically meaningful.

## Current directions

Current questions include how critical and near-critical modes behave under network coarse-graining, how heterogeneous topology changes renormalization flows, and how closure defects can serve as quantitative signatures of emergent behavior.
